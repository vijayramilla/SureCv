## ✅ Verified Functionality

### ✅ Resume Optimization
- Takes raw resume text as input
- Extracts structured data (name, email, phone, employment, education, skills, certifications, projects)
- Calculates baseline ATS score
- Sends to UseResume API for enhancement
- Receives PDF URL + improved ATS score
- Returns all results to frontend

### ✅ Cover Letter Generation
- Takes resume + job description
- Generates professional cover letter text
- Creates PDF version
- Returns both text and PDF URL

### ✅ PDF Downloads
- All PDFs generated by UseResume API
- Signed URLs with 24-hour expiry
- Direct download support
- No server-side PDF generation needed

- 5 credits per resume optimization
- 5 credits per cover letter
- Balance tracked and returned

## 🔍 Troubleshooting

### API Returns 502 Error
→ Check backend server is running: `npm run dev:server`
→ Check UseResume API key is set in `.env`

### CORS Error in Browser
→ Make sure frontend is on allowed port (5173, 5174, 5175)
→ Check CORS config in server/index.js

### PDF Download Fails
→ PDFs expire after 24 hours
→ User needs to re-optimize to get new link

### API Key Not Working
→ Verify `USERESUME_API_KEY` in `.env` starts with `ur_live_`
→ Check credentials haven't been revoked
